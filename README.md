# Romana — Astro Project

Minimal Astro project scaffold.

Requirements
- Node.js (>=16.14 recommended, Node 18+ preferred)
- npm

Quick start

```bash
cd /Users/josefluis/Desktop/Romana
npm install
npm run dev
```

This will start Astro's dev server at http://localhost:3000 by default.

Next steps
- Add TypeScript: `npm install -D typescript` and rename files to `.ts`/`.tsx` if desired.
- Install integrations (Tailwind, React, Svelte) as needed.
